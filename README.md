# Clip Compare

영상과 이미지의 차이를 비교하는 데스크톱 앱입니다.

[최신 설치파일 받기](https://github.com/openerai/clip-compare-updates/releases/latest)

- Windows: `ClipCompare-Setup-<version>.exe`
- Mac 애플 실리콘: `ClipCompare-<version>-arm64.dmg`
- Mac 인텔: `ClipCompare-<version>-x64.dmg`

이 저장소는 설치파일과 업데이트 정보를 배포하는 용도입니다.

## 업데이트

기존 1.0.0 사용자는 1.1.0을 한 번 직접 설치해 주세요. Windows 설치 앱은 이후 새 버전을 자동 확인·다운로드하며, 작업을 마친 뒤 앱 안의 **업데이트 → 재시작 및 설치**로 적용할 수 있습니다. 녹화 중에는 설치가 차단됩니다.

현재 Mac 배포는 업데이트 알림과 다운로드를 지원하며 DMG로 앱을 교체합니다.

비교하는 영상과 이미지는 사용자의 컴퓨터에서만 처리됩니다.
